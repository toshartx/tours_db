# Функциональные требования к проекту

1. Аутентификация и авторизация пользователя
2. Для авторизованного пользователя (**роль** - `игрок`) должна быть возможность: 
> - создать команду (стать капитаном)
> - отправить заявку на вступление в команду
> - выйти из команды
> - просматривать информацию про игроков, команды, турниры и конкретные матчи
> - отправлять жалобы (в дальнейшем - тикеты) на рассмотрение *судьям*
3. Для авторизованного пользователя (**роль** - `капитан`) должна быть возможность:
> - добавить *игрока* путём принятия заявки
> - удалить *игрока* из команды
> - управлять состоянием матча - отправлять счёт в раундах на подтверждение *судье*

> Все остальные возможности *капитан* наследует от *игрока*.

4. Для авторизованного пользователя (**роль** - `судья`) должна быть возможность
> - просматривать тикеты, оставленные *игроками*
> - блокировать доступ к участию в турнирах *игрокам* на основании тикета
> - утверждать результаты матча, оставленные *капитаном* одной из команд

> Все остальные возможности *судья* наследует от *игрока*.

5. Для авторизованного пользователя (**роль** - `организатор/администратор`)
> - создавать и управлять турнирами (аналогично *судье*)
> - назначать судей

> Все остальные возможности *организатор* наследует от *игрока*
6. Журналирование действий пользователя
